Необходимо написать микросервис explAInedReviewService, который будет работать в связке с другими микросервисами.

Данныё микросервис должен работать с комментариями к постам. Сервис, который работает с постами - explAInedArticleService.

Необходимо реализовать базовый CRUD для комментариев, должны быть связи с пользователем, т.е. кто оставил и со статьёй, т.е. куда оставил. Защита по jwt токену, см. другие сервисы.

Использовать C#, ASP.NET MVC, PostgreSQL, по возможности Redis для кэширования, все практики использования брать из других, уже реализованных сервисов. Можешь также использовать другие технологии, какие считаешь нужными.
